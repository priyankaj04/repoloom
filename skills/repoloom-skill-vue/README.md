# repoloom-skill-vue

Claude Code skill for Vue 3. Activates when a project depends on `vue` and guides Claude through the Composition API, `<script setup>` syntax, reactive vs ref decisions, computed properties, watchers, composables, Pinia state management, and typed `defineProps`/`defineEmits`.

Covers: avoiding reactivity loss on destructure, `watchEffect` vs `watch`, composable conventions, Pinia store design, `defineModel()` for two-way binding, `v-for` key discipline, and lifecycle cleanup in `onUnmounted`.

```bash
npx repoloom install vue
```
