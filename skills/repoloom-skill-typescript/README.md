# repoloom-skill-typescript

Claude Code skill for TypeScript. Activates when a project depends on `typescript` and guides Claude through strict-mode configuration, eliminating `any`, proper use of interfaces vs type aliases, discriminated unions, utility types, generics with constraints, and modern features like `satisfies` and `as const`.

Covers: `unknown` + type guards instead of `any`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `import type`, exhaustive discriminated union switches, and module augmentation patterns.

```bash
npx repoloom install typescript
```
