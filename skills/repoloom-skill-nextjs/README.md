# repoloom-skill-nextjs

Claude Code skill for Next.js App Router development. Activates when a project depends on `next` and guides Claude through Server vs Client Components, data fetching strategies, Server Actions, Route Handlers, dynamic vs static rendering, and the `loading.tsx`/`error.tsx` conventions.

Covers: pushing `'use client'` to the leaves, fetch with cache/revalidate options, server action input validation, `generateStaticParams`, Turbopack defaults, `next/image`, `next/font`, and the metadata API.

```bash
npx repoloom install nextjs
```
