# repoloom-skill-react

Claude Code skill for React development. Activates when a project depends on `react` and guides Claude through component design, hooks best practices, performance optimization, error boundaries, and TypeScript prop types.

Covers: single-responsibility components, correct `useEffect` cleanup, avoiding derived-state effects, `useMemo`/`useCallback` only when measured, prop drilling solutions, stable `key` props, and typed event handlers.

```bash
npx repoloom install react
```
